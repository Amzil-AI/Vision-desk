\section{How to read this solution}

This document answers the case \textbf{closed task} with a reference protocol
and sample traces. Section~\ref{sec:lab-run} records metrics from an executed
reference notebook (\texttt{SEED=42}). Other F1 values remain pedagogical.
Non-negotiable: ViT (not LSTM), JSON schema before test, four MCP tools,
and no invented claims.

\section{JSON schema (contract)}

\begin{verbatim}
{
  "type": "candlestick_chart",
  "confidence": 0.989,
  "ticker": "AAPL",
  "fields": {
    "title": "candlestick_chart__doc05_p0",
    "period": "2024"
  },
  "source_tool": "vision.extract"
}
\end{verbatim}

Same payload as the recorded lab sample above (title = image stem).
\texttt{ticker} may be \texttt{null}. Invalid JSON (missing required field)
is a pipeline failure even if the class is correct.

\section{Grounded trace (requirement 1 + 2)}

\paragraph{User question.} ``What type of image is this, and which ticker appears?''

\paragraph{Tools.}
\begin{enumerate}
  \item \texttt{vision.classify} $\rightarrow$ \texttt{\{class: candlestick\_chart, score: 0.989\}}
  \item \texttt{vision.extract} $\rightarrow$ JSON above (\texttt{ticker: "AAPL"})
  \item \texttt{market.lookup("AAPL")} $\rightarrow$ metadata (name, currency) --- stub OK
  \item \texttt{knowledge.search("candlestick")} $\rightarrow$ short glossary --- stub OK
\end{enumerate}

\paragraph{Acceptable final answer.}
``\texttt{vision.classify} labels the image as a candlestick chart (0.989).
\texttt{vision.extract} returns \texttt{ticker=AAPL}.
\texttt{market.lookup} confirms Apple Inc.\ metadata.
I assert no closing price: no price field is present in the JSON.''

\section{Refusal after tool failure (requirement 3)}

\paragraph{Situation.} \texttt{vision.extract} returns \texttt{ticker: null}
(or \texttt{market.lookup} returns an error).

\paragraph{Acceptable.}
``I cannot confirm a ticker: extraction returns null.
I refuse to invent a symbol. Retry with a wider crop / different DPI.''

\paragraph{Unacceptable.}
``It's clearly Tesla.'' --- no tool source.

\section{Penalized anti-patterns}

\begin{itemize}
  \item LSTM or Conv1D on the image ``because deep learning'';
  \item LLM claim without a tool call;
  \item calling \texttt{vision.*} then ignoring the JSON;
  \item presenting a RAG glossary as OCR / extraction;
  \item write / mutate tools inside the lab (read-only MCP only).
\end{itemize}

\section{Typical limits (copy into the 4-page note)}

\begin{enumerate}
  \item \textbf{Layout shift} --- new template $\Rightarrow$ F1 drop.
  \item \textbf{Capture} --- DPI, UI chrome, JPEG compression.
  \item \textbf{Hallucination} --- the LLM fills what the JSON does not have.
\end{enumerate}
